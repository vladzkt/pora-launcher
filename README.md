# Лаунчер «Пора Копать»

Свой лаунчер для гриф-сервера Minecraft [porakopatb.com](https://porakopatb.com): вход по
учётной записи сайта, установка игры и сборки модов, запуск. Игроку не нужно ставить ни Java,
ни Fabric, ни моды руками.

Java 21, Swing, без сторонних библиотек кроме Gson. Открытый код под лицензией MIT.

## Скачать

Готовый установщик для Windows - на [странице загрузки](https://porakopatb.com/download).
Здесь лежат исходники.

## Собрать самому

    ./gradlew fatJar

Готовый джарник в `build/libs/pora-launcher-1.0.0-all.jar`.

Установщик и архив для Windows собирает `tools/pack.ps1`: он зовёт `jpackage` с готовой средой
исполнения и упаковывает результат. Для `--type exe` нужен WiX 3.14.

    powershell -ExecutionPolicy Bypass -File tools\pack.ps1

## Как выкладывать обновления

Обычная правка едет игрокам **одним джарником**, установщик при этом не трогается:

    ./gradlew fatJar
    # в репозитории сайта:
    bash scripts/launcher.sh

Лаунчер при запуске сверяет свою версию с сайтом и подменяет себя сам, поэтому внутри
установщика важно только то, что он не качает: Java и сам механизм обновления.

Установщик пересобираем и выкладываем (`bash scripts/launcher.sh --installer`) только когда
меняется одно из этих двух. Причина не в лени: Chrome и SmartScreen ругаются на файл, который
«скачивают редко», а доверие копится на конкретный файл - каждый новый установщик обнуляет счёт.
За два дня их вышло девять, и предупреждение у игроков не уходило по нашей же вине.

Версию в `build.gradle` при этом поднимаем всегда: по ней лаунчер и понимает, что пора обновиться.

## Проверить без окна

    java -jar build/libs/pora-launcher-1.0.0-all.jar --check      # что отдаёт сайт
    java -jar build/libs/pora-launcher-1.0.0-all.jar --install    # скачать всё, не запуская игру
    java -jar build/libs/pora-launcher-1.0.0-all.jar --shot ok.png  # нарисовать окно в файл

## Что он делает

1. Отправляет ник и пароль на `POST /api/launcher/login`, получает разовый ключ на пять минут.
2. Берёт список сборки с `GET /api/launcher/manifest` и качает недостающее из `/pack/`.
3. Ставит Minecraft и его ресурсы с серверов Mojang, загрузчик Fabric - с их же.
4. Запускает игру, передавая ключ через `-Dporakopatb.token`.

Пароль никуда не сохраняется: он живёт ровно до ответа сайта. Запоминается только ник.

Всё скачанное проверяется по сумме, поэтому повторный запуск ничего не качает заново, а
оборванная загрузка не оставляет за собой битого файла. Игра живёт в `%APPDATA%\.porakopatb`
и не мешает другим сборкам Minecraft.

## Как устроено

| Файл | За что отвечает |
|---|---|
| `Launcher.java` | окно, порядок действий, состояния кнопки и полосы |
| `Skin.java` | цвета, шрифты и самодельные детали окна |
| `Site.java` | разговор с сайтом: вход и список сборки |
| `Installer.java` | игра, библиотеки, ресурсы, Fabric и моды |
| `Game.java` | сборка команды запуска и сам запуск |
| `Files2.java` | суммы, обход папок, распаковка нативных библиотек |

## Почему HttpURLConnection, а не HttpClient

Новый клиент поднимает внутреннее соединение через петлю, и на машинах, где антивирус её
запрещает, не создаётся вовсе - падает с «Unable to establish loopback connection». Старый
`HttpURLConnection` такого не делает.
